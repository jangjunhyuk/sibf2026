# 2026 서울국제도서전 부스 배치도 (SIBF 2026 Booth Map)

2026 서울국제도서전의 부스 배치 정보를 확인하고 검색할 수 있는 웹 기반 애플리케이션입니다. 관람객들이 효율적으로 부스를 찾고 정보를 탐색할 수 있도록 돕습니다.

## 🤖 제작 정보
이 프로젝트는 Claude의 도움을 받아 설계 및 구현되었습니다. 데이터 시각화와 인터랙티브 UI 개발 과정에서 Claude와 협업하여 효율적인 코드 구조를 완성했습니다.

## 🚀 주요 기능

* **부스 목록 조회**: 전체 부스 리스트를 한눈에 확인 가능합니다.
* **부스 위치 검색**: 출판사 이름, 부스 번호, 국가 정보를 통해 원하는 부스를 빠르게 찾을 수 있습니다.
* **인터랙티브 지도**: 행사장 전체 배치도를 지도 형태로 시각화하여 부스 위치를 직관적으로 파악할 수 있습니다.
* **상세 정보 제공**: 각 부스 클릭 시 해당 부스의 상세 정보(이름, 영어명, 위치 등)를 확인할 수 있습니다.
* **반응형 UI**: 모바일 환경에서도 최적화된 사용자 경험을 제공합니다.

## 🛠 사용 기술

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
* **UI/UX**: Pretendard 폰트 적용, 다크 모드 기반의 Immersive UI
* **Architecture**:
* `RAW` 데이터 구조를 활용한 실시간 검색 및 필터링 기능
* Canvas 기반의 지도 렌더링 및 인터랙션



## 📂 프로젝트 구조

```text
.
├── index.html  # 메인 애플리케이션 파일
└── README.md   # 프로젝트 설명 파일

```

## 📝 사용 방법

1. 이 레파지토리를 클론(Clone)하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저(Chrome, Safari 등)로 엽니다.
3. 검색창에 원하는 출판사나 부스 번호를 입력하여 검색합니다.
4. 목록(List) 모드와 지도(Map) 모드를 전환하며 원하는 부스를 확인합니다.
